# Внешние источники: что проверено и что из этого получилось

Все проверки сделаны запросами с сервера проекта (Санкт-Петербург). Капчу и антибот-защиту мы не обходим,
ограничения `robots.txt` соблюдаем. Если источник закрыт — он помечен как непригодный, данные из него не имитируются.

## Почему нельзя восстановить участников закупок АИС ГЗ

В датасете по АИС ГЗ записан только победитель. Мы проверили, можно ли достать остальных участников из ЕИС
по номеру извещения (`reqnum`, пример — `0372200084723000029`):

- страница результатов и протокол открываются;
- в протоколе видно: «Подано заявок: 2 (соответствует требованиям: 2, отклонено: 0)»;
- у каждой заявки — **идентификационный номер участника** (например, 377976), дата подачи, место и цена.
  **ИНН и названий проигравших в протоколе нет** — по 44-ФЗ участники электронных процедур обезличены,
  известен только победитель (через контракт).

Вывод: узнать, кто проиграл, из открытых данных нельзя. Можно узнать только **число заявок** в процедуре.
Но и это массово собрать не получится: в `robots.txt` ЕИС указано `Crawl-delay: 60` (один запрос в минуту),
а процедур с номером ЕИС в данных 231 тысяча — это 160 суток. Массовых выгрузок (FTP) больше нет.

Поэтому долю побед мы по-прежнему считаем только по Электронному магазину, где видны все участники,
а победы в АИС ГЗ показываем отдельно с оговоркой.

## Почему в «Новых компаниях» нет крупных производителей

Чтобы найти компанию по виду деятельности, нужен её ОКВЭД или перечень продукции. Для крупных компаний
открыто и массово этого нет:

- ГИСП (самый прямой источник «производитель по коду ОКПД2») закрыт антибот-защитой;
- победители закупок по всей России в ЕИС — те же ограничения: один запрос в минуту и нет выгрузок;
- в открытых наборах ФНС по численности и выручке нет вида деятельности, а ЕГРЮЛ массово не публикуется.

Что сделали вместо этого: взяли из полной выгрузки реестра МСП не только Петербург и область,
а ещё **производителей (ОКВЭД 10–32, малые и средние предприятия) и средних оптовиков из всех регионов**.
Для закупок товаров они показываются в блоке «Новые компании» (не больше 40% списка);
для услуг и работ остаются только местные компании.

Размер компании указывается только по данным реестра МСП: микро, малое, среднее.
Если компании в реестре нет — пишем «размер не определён», а не «крупная»: подтвердить это нечем.

## Про частоту запросов к ЕИС

Проверка по реестру недобросовестных поставщиков делается поиском на zakupki.gov.ru. Ограничение сайта —
один запрос в минуту для автоматических обходов. Первый прогрев кэша (12 тысяч поставщиков) мы сделали быстрее,
не посмотрев `robots.txt`, — это ошибка, больше массовых обходов не запускаем. В работе сервис обращается
к ЕИС только за теми поставщиками из выдачи, которых ещё нет в кэше, не более 3 запросов на один поиск.

## Что можно сделать дальше, если будет доступ

  по процедурам АИС ГЗ и победителей по всей России.

- Платный доступ к ЕГРЮЛ — вид деятельности крупных компаний.
